# Accounting

Exact money arithmetic of the [accounting contract](../../../../docs/contracts/accounting.md):
nano-dollar amounts, reviewed tariffs, rates in force, reservation bounds, settlement charges
and budget admission decisions. Pure domain code; mutation testing covers it.

Use the [public entry point](__init__.py); private implementation files are not an integration API.

See [specification.md](specification.md) for the interface, behaviour and acceptance criteria.
