# M01 — Earlier incremental practice

During C01, reading and research, decisions about the next step, implementation,
documentation and testing alternated. A single coordinator, also responsible for
implementation, held the main responsibility. Extensive specifications and quality
checks already existed; the work did not start without a design.

The concern expressed by the user was that this alternation could cause repeated
reading, context changes and corrections to completed work. The retrospective
analysis identified a substantial block of reading, deliberation and testing.
It cannot attribute all of that time to avoidable rework or establish that the
architecture was continually rewritten.

See the [C01 results and limitations](../cycles/001-baseline-2026-09-28/report.md).
[M02](002-phased-sprint.md) was agreed to test whether preparing the complete
sprint and separating its phases could reduce repeated work, with parallel
implementation as an additional improvement.
