# features/editor

The graph editor of journeys J1–J3: document model, autosave of the working copy with
undo and activated versions, header, React Flow canvas with its toolbar and outline,
palette, inspector, node dialogs, automatic arrangement, validation, status bar, the run
request and the slot for the history panel; plus the read-only `GraphPreview`. Public
entry: `index.ts`. See the [specification](specification.md).
