# ui

Presentation primitives shared by the features: buttons, icon buttons, icons, kind
tiles, menus, dialogs, tabs, form controls, configuration rows, recorded content, money
and status text; and the generic configuration controls that render a
[component declaration](../../../docs/contracts/component-declaration.md) with its
presentation attributes. It uses the design tokens of `app/styles/base.css`. No feature
imports and no network access. See the [specification](specification.md).
